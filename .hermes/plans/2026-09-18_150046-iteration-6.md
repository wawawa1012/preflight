## 冻结口径（DS 不许改，改了就是扩权）

- 状态词：有引用 →「已核证引用 N 条」。零引用 →「当前范围尚未发现引用」+ 范围句（文件名 + Block 数）。**不要**单独一颗「缺失」芯片当唯一信息；若出现「缺失」二字必须紧跟范围句。
- 禁止：已满足、已支撑、覆盖率、就绪度、✅❌、分数、Trust Layer、证据基础设施、Supports、Submission readiness。首页禁止「准备答辩」。
- I6 五秒口吻（首页验收）：「这是一个按评审标准预审材料、把每条要求点回原文的工具。」

- 零引用的解释必须能答三问：范围=该材料全部 Block；原因=已核证关联数为 0；依据=没有可点的引用，展示范围句，并提供去详情页标注/预检的入口。

"""材料级预审快照：只读装配，不写库、不做满足判定。"""
from pathlib import Path

from . import rubric_store, storage
from .contracts import (
    MaterialPreflightCitation,
    MaterialPreflightCriterionRow,
    MaterialPreflightMissing,
    MaterialPreflightReport,
    MaterialPreflightSummary,
)
from .storage import RubricNotBound

SCOPE_TMPL = (
    "当前范围尚未发现引用：已核对材料「{filename}」的 {n} 个 Block 上全部已核证关联，"
    "本评分要求已关联 0 条。这不是证明材料外不存在证据。"
)


def assemble_report(material_id: str, db_path: Path | None = None) -> MaterialPreflightReport | None:
    material = storage.get_material(material_id, db_path=db_path) if db_path is not None else storage.get_material(material_id)
    if material is None:
        return None
```

签名：材料不存在返回 `None`（API 先 `material_exists` 再调用，见工作包 D）。未绑定抛 `RubricNotBound("该材料尚未绑定评分标准")`；绑定了但 rubric 文件没了抛 `RubricNotBound("绑定的评分标准版本已不可用", [f"{id} rev{n}"])`（与 `main.py:245` 同文案）。**禁止** `LookupError` / `ValueError` 玩笑行。

装配逻辑（必须按此，不要发明 FTS）：

```
binding = storage.get_binding(...)
if binding is None: raise RubricNotBound("该材料尚未绑定评分标准")
rubric = rubric_store.get_rubric(binding.rubric_id, binding.rubric_revision)
if rubric is None: raise RubricNotBound("绑定的评分标准版本已不可用", [...])
links = storage.list_links(...)
annotations = {a.id: a for a in storage.list_evidence_annotations(...)}
blocks_by_id = {b.id: b for b in material.blocks}
rows = []
for criterion in rubric.criteria:
    crit_links = [l for l in links if l.criterion_id == criterion.id]
    citations = []
    for link in crit_links:
        ann = annotations.get(link.annotation_id)
        if ann is None:
            continue  # 关联残留不该发生（FK CASCADE）；跳过，不要崩
        block = blocks_by_id.get(ann.block_id)
        line = block.locator.index if block else 1
        citations.append(MaterialPreflightCitation(
            link_id=link.id, annotation_id=ann.id, criterion_id=criterion.id,
            block_id=ann.block_id, line_number=line, quote=ann.source.quote,
            rationale=link.rationale, proposed_by=link.proposed_by,
            start=ann.source.start, end=ann.source.end,
        ))
    if citations:
        rows.append(MaterialPreflightCriterionRow(..., status="has_verified_citations",
                    verified_citation_count=len(citations), citations=citations, missing=None))
    else:
        rows.append(..., status="no_verified_citations_in_scope", verified_citation_count=0,
                    citations=[], missing=MaterialPreflightMissing(
                        searched_block_count=len(material.blocks),
                        searched_filename=material.filename,
                        explanation=SCOPE_TMPL.format(filename=material.filename, n=len(material.blocks)),
                    ))
