# Golden 演示材料（产品体感，不是合成堆字）

1. 上传 `scheme.md`，打开报告：关键陈述立即出现；「待处理问题」应为召回率 **88% vs 93%**（同材料）。抽取准确率 95% 在单份里只有一处，不会进待处理。
2. 再上传 `test_report.md`。
3. 打开 `/compare`，选 scheme.md × test_report.md：应为抽取准确率 **95% vs 89.7%**（不要出现三值 91/95/89.7）。空结果不是功能坏了——中英试卷那种文件没有同度量词冲突。
4. 不要用 `data_structure_exam_en.md` × `_zh.md` 演示对照。
