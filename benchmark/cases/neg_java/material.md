## 一、选择题

1. 下列关于单链表的说法中，正确的是（ ）
   A. 单链表必须占用连续的内存空间
   B. 单链表的插入和删除操作不需要移动元素
   C. 单链表不能进行随机访问
   D. 单链表的头结点一定存放数据

2. 在长度为 n 的顺序表中间位置插入一个元素，平均需要移动的元素个数是（ ）
   A. n/2
   B. n
   C. 1
   D. log n

## 二、程序填空

3. 阅读下面的 Java 代码，补全冒泡排序的内层循环条件：

```java
for (int i = 0; i < arr.length - 1; i++) {
    for (int j = 0; j < ______; j++) {
        if (arr[j] > arr[j + 1]) {
            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}
```
