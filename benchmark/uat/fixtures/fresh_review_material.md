# 新鲜 Review 材料模板（每次重写一份，≤50 行）

> 用法：每次 Gate 运行前，tester 按此骨架**重写一份新的**（换主题、换数字、换措辞），不要复用上一轮的、不要抄 golden-v2、不要用真实赛事全文或私有材料。tester 自己知道真相（哪句真、哪句夸大），题目不给答案。

```markdown
# {自选题目：如 校园共享雨伞方案}

## 背景（3-5 行，真话）
{为什么做、给谁用，一句话痛点。}

## 方案（5-8 行，真话为主，可埋 1 个夸大句并记下来）
- {做法 1：具体动作}
- {做法 2：具体动作}
- {夸大句（如用）：如"首创/第一/100%"——tester 记下来，但材料里不标注。}

## 数据（3-5 行，含 1-2 个数字，自己记得真值）
- {测试了多少条、什么条件，数字：____}
- {另一处可埋矛盾数字：同一数字换个写法，tester 记下来。}

## 局限（2-3 行，诚实写 1 个没做的事）
- {没做的事：如"未在雨天高峰实测"。}
```

## 自检（提交前打勾）

- [ ] ≤50 行、全 Markdown、无图片无附件。
- [ ] 我知道哪句是夸大/矛盾（写在自己的 tester 笔记里，不写进材料）。
- [ ] 与上一轮主题不同，与 golden-v2 无逐句雷同。
