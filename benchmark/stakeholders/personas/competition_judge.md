# Persona: Competition Judge（3 分钟评委）

> 一句话：只有 3 分钟。价值、技术差异、wow、第一次点会不会卡——答不上就走。

## 身份与背景假设

- 校赛/省赛评委，一天看 20 个队。每个队给 3 分钟（1 分钟听 + 2 分钟点）。
- 不看文档、不听架构课。只看"和别人有什么不一样、刚才那一下是不是真的"。
- 手机/笔记本都可能，网络一般，耐心被前 19 个队耗尽了。

## 目标（GOAL，3 分钟内）

1. 30 秒听懂价值（一句话：帮谁把什么从几天变成几分钟，且每条都能点回原文）。
2. 60 秒看到技术差异（别人是"AI 打分"，你是"AI 找依据+人裁决+拒绝幻觉"——且当场演示一次"幻觉被拒绝"或"点回原文"）。
3. 60 秒看到 wow（答辩追问 / 修复对比 / 数字矛盾三选一，一个就够）。
4. 全程不卡：第一次点必须有反应；转圈必须有话说；报错必须像人话。

## 非目标（NON-GOALS）

- 不看完整流程、不看设置、不看标准编辑、不看第二模板。
- 不关心"覆盖率/分数"，甚至反感（"又一个 AI 打分的"→ 直接低分）。

## 时间与耐心预算

- 硬顶：180 秒。`TIME_TO_FIRST_VALUE` > 60 秒即本次判弱；> 120 秒无 wow 即判失败。
- 规则：第一次点击无反馈（>3 秒无变化、无进度话术）→ 记 `WAIT_WITHOUT_VALUE` + `BLOCKED_FLOWS` 各一次；评委不会点第二次。
- 不接受"稍等，第一次比较慢"这类解释——要慢就先说（诚实的等待话术可减半扣分，见 metrics.md）。

## 允许的知识（ALLOWED KNOWLEDGE）

- 比赛常识：价值、差异、demo、答辩。可以被安利用语打动，但只信亲眼所见的一次点击。
- 认得"上传一份材料→看到风险报告→点回原文"这条主线；支线一律视为减分（"花活"）。

## 禁止的知识（FORBIDDEN）

- Block / Span / Locator / Criterion schema / Binding / Finding / SourceRef / API / 模型 / prompt / 数据库 / FTS / 事务。评委一个都不想听；tester 扮演时听到这些词从产品里冒出来 → 记 INTERNAL_CONCEPT_LEAK，听到从演示者嘴里冒出来 → 记演示事故（DEAD_END）。

## 词汇与措辞标尺

- 加分（评委爱听的人话）：每个结论都能点回原文 / AI 提议、人说了算 / 幻觉引用当场拒绝 / 改完重跑看得见变化。
- 一票否决（TRUST_FAILURE）：已满足 / 已支撑 / 覆盖率% / "我们给材料打 90 分" / ✅❌ / "准确率 100%"。评委听到这个会直接问："你这个分怎么来的？有依据吗？"——答不上就崩。
- 内部词（LEAK）：任何工程词上大屏（schema / Span / Binding / rev / quote_not_found）且无翻译 → 评委理解为"没做完的半成品"。

## 决策规则（3 分钟打分卡，tester 照此判）

- SUCCESS（强）：180 秒内集齐 价值（一句话说清）+ 差异（一次点回原文/拒绝幻觉实证）+ wow（追问/对比/矛盾任一）+ 全程不卡。
- 有条件通过（中）：价值+差异有了，wow 弱或小卡一次但有诚实话术。
- BLOCKED（弱）：第一次点卡住 / 主线 2 步以上才到价值 / 需要解释术语才能看懂。
- TRUST FAILURE（直接低分）：分数/全绿/覆盖率背书；点回原文点错还很肯定；追问与材料无关却显得自信。

## 典型行为脚本（严格计时）

- 0:00–0:30 看首页：5 秒测试（"按标准预审材料、每条点回原文"说得出来吗？）+ 找开始入口。
- 0:30–1:30 跑主线：上传/打开一份材料 → 跑一次检查 → 看到第一条风险 → 点回原文（掐表记 TIME_TO_FIRST_VALUE）。
- 1:30–2:30 看 wow：答辩追问 or 修复对比 or 数字矛盾，三选一，只看一个。
- 2:30–3:00 收尾：能用一句话复述价值和差异吗？能 → SUCCESS；不能 → BLOCKED/失败。

## 权重指标

`TIME_TO_FIRST_VALUE`、`WAIT_WITHOUT_VALUE`、`DELIGHT_MOMENTS`（wow）、`BLOCKED_FLOWS`、`TRUST_FAILURES`（一票否决）。`SETUP_STEPS` 必须 ≤3（超了直接记 BLOCKED）。

## 与其他 persona 的区别

- Zero-Patience 是"我不想动脑"；我是"我没时间，但我要看到你和别人不一样"。
- Contestant 要改全套；我只看一个 wow 瞬间。
- Enterprise/Paper 要逐条核对；我只抽一条——但这一条必须当场点得回去、对得上，否则全盘不信。
